# مدير الشقق (المرحلة 1)
## التشغيل محليًا
1. `npm install`
2. انسخ `.env.example` إلى `.env` وضع قيم مشروع Supabase (المفتاح العام anon فقط، لا تضع Service Role أبدًا).
3. `npm run dev`
## إعداد Supabase
1. أنشئ مشروعًا في supabase.com.
2. من SQL Editor شغّل محتوى `supabase/schema.sql`.
3. Authentication > Users > Add user لإنشاء حساب المالك، ثم عطّل التسجيل العام من إعدادات Email.
## النشر
Vercel أو Netlify: اربط المستودع، أمر البناء `npm run build`، المجلد `dist`، وأضف متغيري البيئة نفسيهما.
## الحالة
- مكتوب: المخطط الكامل (الجداول، RLS، قيود السرير والطاقة والدفعات)، الدخول، الرئيسية، الشقق (إضافة/أرشفة)، المهام (إضافة/إكمال).
- لم يُختبر: لم يُشغَّل شيء بعد (بيئة التطوير بلا إنترنت).
- متبقٍ: واجهات المقيمين والنقل والمدفوعات والحسابات والتقارير وCSV والطباعة وتعديل الشقق وصفحة التفاصيل.
